\chapter{Lista dodatkowych plików, uzupełniających tekst pracy (jeżeli dotyczy)}

W systemie do pracy dołączono dodatkowe pliki zawierające:
\begin{itemize}
    \item kod źródłowy warstwy interfejsu użytkownika aplikacji Stylify, zaimplementowanej z~wykorzystaniem biblioteki React,
    \item kod źródłowy warstwy serwerowej aplikacji, odpowiedzialnej za obsługę logiki biznesowej oraz komunikację z~bazą danych,
    \item moduł ML-service, realizujący proces klasyfikacji wiadomości z~wykorzystaniem wytrenowanego modelu uczenia maszynowego,
    \item zbiory danych wykorzystane podczas procesu trenowania i~ewaluacji modeli,
    \item skrypty służące do przygotowania danych, trenowania modeli oraz przeprowadzania eksperymentów,
    \item wytrenowany model wraz z~niezbędnymi plikami konfiguracyjnymi, umożliwiający odtworzenie uzyskanych wyników badań,
\end{itemize}
